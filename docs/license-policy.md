# License Policy

## Project License

App Factory Supervisor is licensed under LGPL using SPDX identifier `LGPL-3.0-or-later` unless a
future license file states otherwise.

## Generated Apps

Generated Android app projects are separate works and should declare their own license. The
supervisor app license does not automatically choose the generated app license.

## Third-Party Dependency Review

Before adding dependencies, review license compatibility, source, version, and maintenance status.
Record dependency decisions in project documentation when the dependency affects distribution,
security, privacy, or build reproducibility.

Dependencies with unknown, custom, source-unavailable, copyleft-incompatible, or commercial-only
terms require explicit review before use.
